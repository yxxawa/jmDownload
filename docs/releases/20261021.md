# 20261021

本次更新：**Windows 1.1.4**。Android 继续提供 **1.3.5（versionCode 10）ARM64** 安装包。

### Windows 图片与封面修复（2026-10-30）

- 修复 Windows 内嵌资源名称中的路径分隔符，解决头像、角色插画和示例封面在发布程序中加载失败的问题。
- 移除封面的半透明黑色渐变；编号和选择按钮使用局部浅色底，封面保持原色，深浅主题及悬停状态一致。
- 发布自检覆盖全部 25 项前端资源、响应类型和 WebP 解码，并在不依赖源码文件的环境中验证。
- 按原有自包含单文件方式重建 Windows x64／ARM64，替换本 Release 的两个 EXE；版本号仍为 1.1.4。
- `main` 与原有 `20261021` 标签同步修复，Release 的自动源码归档包含本次修改。

### PC 界面更新

- 与安卓统一橙白配色、Q 版图标和角色形象，重做导航、作品卡片、详情、下载任务与空状态。
- 宽屏使用左侧导航、中央作品区、右侧下载清单；小窗口自动切换为下载抽屉，支持点击遮罩和 Escape 关闭。
- 新的原生启动页、进度动画、卡片入场与弹窗过渡，支持深色模式和“减少动效”。
- 按反馈删除首页宣传横幅、左下角插画寄语和品牌副标题，作品列表直接放在搜索框下方。
- 修复阅读器设置加载完成后覆盖当前主题的问题。

### 从最近阅读查看详情

- 点击书架中作品的封面、书名或卡片内容，加载作者、标签、页数、章节目录与阅读进度。
- “继续阅读”仍直接回到保存的页码，收藏、删除和批量管理操作保持独立。
- 作品详情标签仍可点击跳转搜索；本次书架详情入口改动用于 PC 端。

### 下载安装

| 设备 | 文件 | 大小 |
| --- | --- | --- |
| Intel / AMD Windows 电脑 | `JMDownload-win-x64.exe` | 64.0 MiB |
| Windows on ARM64 | `JMDownload-win-arm64.exe` | 60.2 MiB |
| 64 位安卓手机 | `JMDownload-android-arm64.apk` | 22.3 MiB |

Windows 为自包含单文件程序，继续保留 .NET、WPF、WebView2 桥接和 SkiaSharp 图片处理依赖；系统仍需安装 **WebView2 Runtime**。

安卓沿用上版的 ARM64 安装包、包名与原签名，可覆盖安装并保留数据；不提供通用 APK。本次未修改安卓程序版本。

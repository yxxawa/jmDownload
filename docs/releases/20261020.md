# 20261020

本次更新：**Android 1.3.5（versionCode 10）／Windows 1.1.3**。

### 点击标签直接搜索

- 点击作品详情里的标签，自动关闭详情、回到搜索页，填入标签并展示相关结果。
- 手机端不强制弹出键盘；电脑端可用键盘回车激活标签。
- 支持中文与带空格、引号、符号的标签；无标签时保持普通提示。

### 安卓界面与启动体验

- 重做移动端布局、明暗主题、底部导航、详情面板、章节目录与加载反馈。
- 使用原创角色「橙奈」与 Q 版应用图标，在开屏、快捷入口和空状态中统一呈现。
- 先绘制原生人物加载页，再初始化 WebView；首页可用后等待 WebView 首帧再淡出，移除固定 3 秒撤下遮罩的逻辑。
- Android 13 及以上优先显示系统开屏图标，通知权限申请延后到首页显示后。
- 修复搜索输入文字不可见、焦点边框不贴合，以及章节目录偶发无法滚动的问题。
- 优化长章节可见页定位、图片预取和回收，减少下载进度更新时重复刷新列表；品牌图片改用压缩 WebP。

### 安装包与依赖

| 设备 | 文件 | 大小 |
| --- | --- | --- |
| Intel / AMD Windows 电脑 | `JMDownload-win-x64.exe` | 63.0 MiB |
| Windows on ARM64 | `JMDownload-win-arm64.exe` | 59.2 MiB |
| 常见 64 位安卓手机，推荐 | `JMDownload-android-arm64.apk` | 22.3 MiB |

Windows 保留自包含 .NET／WPF、WebView2 桥接及 SkiaSharp 图片处理依赖。默认只携带简体中文、繁体中文和内置英文提示，不携带开发用 PDB；源码构建可用 `-IncludeAllLanguages` 恢复所有可选翻译。**系统仍需安装 WebView2 Runtime。**

安卓仅发布 ARM64 精简包，沿用原有包名和签名，可覆盖安装并保留数据。
